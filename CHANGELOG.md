# Changelog

## 1.0.0 — 2026-11-21

- First standalone release of Cloudberry Pi AppPilot.
- Added `cbapp` command-line interface and application catalogue.
- Added user-local installation and compatibility commands `app-install` and `app-uninstall`.
- Added GIMP ARM64 AppImage installation with official SHA-256 verification and per-user Flatpak fallback.
- Added JetBrains Toolbox ARM64 release discovery and installation.
- Added TurboWarp ARM64 AppImage installation with GitHub release digest verification when available.
- Added generic local AppImage management.
- Added `list`, `status`, `doctor`, `update`, `remove` and `self-uninstall` commands.
- Added no-root enforcement, user-local paths, logs, lock handling and download failure checks.
